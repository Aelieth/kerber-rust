# A4 — kadmind's RPC front door

The front door of kadmind's RPC port, the part of section A4 that sits between the socket and the verbs: which
acceptor name each program takes, the listeners and the programs registered on them, and where the GSS acceptor
reads its key. The verbs carried over it are in [a4-kadmin.md](a4-kadmin.md); the gssrpc layer's own checks
(`svc.c`, `svc_auth_gssapi.c`, `ipropd_svc.c`) are in [A5](a5-prop.md).
