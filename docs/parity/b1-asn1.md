# B1 — the ASN.1 decoder (`lib/krb5/asn.1`)

How MIT 1.22.2's `asn1_encode.c` and `asn1_k_encode.c` decode a Kerberos message, against the
Rust decoder: the crates' types over `vendor/rasn`, crates.io's rasn 0.28.14 with the decode rules
`vendor/rasn/PATCHES.md` lists. A Rust site is the crates' decode entry point or the wire type that
carries the rule; the rasn function is named beside it. The decode sweep (`crates/krb5-tools`,
`asn1_sweep.rs`) breaks every explicit field and SEQUENCE OF element of 41 message types; its unit
test holds the Rust decoder to MIT's committed answers and `asn1-decode-oracle-gate` asks MIT live.
The client library is in B1's other files, [b1-client.md](b1-client.md),
[b1-gss.md](b1-gss.md) and [b1-tools.md](b1-tools.md).
