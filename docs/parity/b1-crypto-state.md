# B1 — the cipher state between messages (lib/crypto)

What `krb5_c_encrypt` and `krb5_c_decrypt` leave in the cipher state that chains one message to the next, as `krb5_mk_priv` and `krb5_rd_priv` use it through kprop's blocks: AES and Camellia (done), rc4-hmac and des3-cbc-sha1 (deferred). The rest of the client library is in [b1-client.md](b1-client.md).
