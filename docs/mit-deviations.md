# Deviations from MIT 1.22.2

This file holds the deliberate deviations from MIT 1.22.2, the invariants
recorded in the [parity ledger](parity/README.md) (which has the per-function
grades) and the parity decisions that are not deviations. New deviation rows go
in this file. The timing, replay and secret-handling matrix is in [security.md](security.md).

## Documented deviations from MIT 1.22.2

These are deliberate. Unless a row says otherwise they fail closed (Rust
rejects or bounds where MIT would accept or grow); the transited-bounds
row is MIT-exact and the FAST-outer 149 row is a KDC coverage
superset. Honest UTF-8 paths are not laxer than MIT; the UTF-8 transited
row below is mixed on absurd inputs.
